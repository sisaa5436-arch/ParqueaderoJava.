# ParqueaderoJava - Deber 1

Aplicación académica de consola para Eclipse y Java 17, sin dependencias externas.
Registra entradas y salidas, cobra USD 0,50 por hora o fracción y conserva los datos
en `vehiculos.txt` y `caja.txt` dentro del directorio de ejecución.

El informe y las instrucciones completas se incorporan al finalizar la validación.
